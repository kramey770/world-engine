# Asset credits

This showcase uses selected assets from Quaternius's Universal Base Characters, Modular Character Outfits - Fantasy, Universal Animation Library, and Universal Animation Library 2 packs. The character, rigged short parted hair, modular peasant outfit, and animation clips are included under the CC0 1.0 Universal Public Domain Dedication: https://creativecommons.org/publicdomain/zero/1.0/.

The character uses `Superhero_Male_FullBody`, the matching rigged `Hair_SimpleParted` mesh, and male peasant clothing components. Non-combat animation clips from both libraries are applied to the character's rig. Natural-material eyebrows are tinted to match the short dark hairstyle.
