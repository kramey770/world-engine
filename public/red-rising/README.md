# Red Rising demo artwork

These local files were downloaded on 2026-09-09 from image URLs embedded in the author-hosted Red Rising Saga page:

- `series.webp` and `author-site-feature.webp`: `https://www.piercebrown.com/redrisingsaga`
- `red-rising-cover.webp`: `https://www.piercebrown.com/redrisingsaga`

They are included only as local demo artwork for stress-testing World Engine's canon image fields. Confirm rights and attribution before shipping them in a public product.

Additional local reference images were downloaded from Wikimedia Commons through its `Special:FilePath` endpoint:

- `mars.webp`: OSIRIS Mars true-color image
- `moon.webp`: Full Moon image
- `earth.webp`: Earth photographed by Apollo 17
- `space.webp`: Milky Way panorama

These are used as broad category artwork for the demo. The image assignments are intentionally thematic rather than claims that the photographs depict fictional locations or characters.

Saga-specific assets cached from the supplied sites:

- `author-rrsm.jpg`, `author-saga-1.jpg`, `author-saga-2.jpg`: image URLs exposed by the Pierce Brown Red Rising Saga page
- `official-banner.jpg`: image URL exposed by the official Red Rising site
- `character-jackal.png`, `character-apollonius.png`, `character-ajax.png`, `character-alexandar.png`: character image URLs exposed by the Bookworm AI Red Rising reference

The four character assets are assigned to their matching character records. The saga and official assets are used as source-specific thematic artwork where the supplied sites did not expose a portrait for that subject.
